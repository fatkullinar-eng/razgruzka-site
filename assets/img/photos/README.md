# Фото для сайта «Разгрузка»

Сюда можно складывать исходные фотографии.

## Как правильно

- Формат: JPG, PNG или WebP.
- Размер: 1600–2400 px по длинной стороне.
- Вес: 1–2 МБ на фото (не больше 5 МБ).
- Имена — латиницей, без пробелов: `master-anna.webp`, `cabinet-wide.webp`, `couch.webp`.
- Не удаляйте и не переименовывайте уже подключённые файлы без предупреждения.

## Что нужно

| Файл | Куда на сайте | Формат |
|---|---|---|
| `hero.png` / `hero.webp` | первый экран | вертикальный, 4:5 |
| `master-anna.webp` | блок «Мастер» | вертикальный, 4:5 |
| `cabinet-wide.webp` | галерея, широкая плитка | 3:2 |
| `couch.webp` | галерея | 4:3 |
| `light.webp` | галерея | 4:3 |
| `details.webp` | галерея | 4:3 |
| `atmosphere.webp` | галерея | 4:3 |
| `entrance-wide.webp` | галерея, широкая плитка | 3:2 |

## Статус

Фото уже подключены к сайту:

- исходники лежат здесь;
- оптимизированные копии для сайта — в `../site/`;
- портрет мастера стоит в блоке «Мастер»;
- шесть кадров стоят в галерее.

Если замените исходники, скажите агенту — он пересоберёт оптимизированные копии и обновит страницу.

После подключения Supabase новые фото лучше загружать через кабинет: они будут храниться в облаке и открываться с любого устройства.
